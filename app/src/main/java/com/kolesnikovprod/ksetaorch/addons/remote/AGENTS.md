# Addon remote files

> `@since 0.3`

Этот package содержит единственный общий Ktor-механизм загрузки файлов
addon-платформы. Он проверяет HTTPS/redirect policy, ограничивает размер,
потоково пишет временный `.part` и атомарно завершает файл.

Контур не знает, является файл APK или изображением. SHA-256, Android package
identity, bitmap dimensions и остальные семантические проверки выполняются
владельцем конкретного артефакта.

Нельзя добавлять второй самостоятельный Ktor downloader для нового типа
addon-ресурса. Новый потребитель должен использовать
`KtorAddonRemoteFileDownloader` и наложить собственный verifier.
